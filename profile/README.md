# Discindo

Discindo is a small organisation that builds open-source tools, mostly
R packages for data visualisation, data collection and deployment.
We write about our work on the [Discindo blog](https://discindo.org/).

## Packages

| Package | What it does | Install |
|---|---|---|
| [ggindex](https://github.com/discindo/ggindex) | A ggplot2 geom that marks selected points of a plot with numbered markers and explains them in a legend, as on an annotated map. | `install.packages("ggindex")` |
| [r2lambda](https://github.com/discindo/r2lambda) | Build, test and deploy R scripts as AWS Lambda functions packaged in Docker images; invoke, schedule and delete them from R. | `pak::pak("discindo/r2lambda")` |
| [newscatcheR](https://github.com/discindo/newscatcheR) | Fetch news from the RSS feeds of thousands of news sites without looking up feed addresses; filter sites by topic, country and language. | `install.packages("newscatcheR")` |
| [gghisse](https://github.com/discindo/gghisse) | Summarise and plot results of HiSSE and MuHiSSE models from the hisse package, with a Shiny app for exploring them. | `pak::pak("discindo/gghisse")` |
